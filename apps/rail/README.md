# rail

The soopdoop rail. `prototype.html` is the approved clickable design (example data). Phase 1 step 3 replaces its example data with live Convex queries:

| Prototype | Convex |
| --- | --- |
| roster (friends, LEDs, agent counts) | `friends.list` |
| knock card, pending chip | `knocks.incoming`, `knocks.decide` |
| "@you knocked" outcomes | `knocks.sent` |
| your subset | `subsets.mine` |
| focus mode | `hackers.setFocus` |

It ships two ways: a slim always-on-top window beside Superset, and the same page published as a Superset Page so it can sit in a workspace pane.
