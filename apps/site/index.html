Knock

Send a link, a page, a file or a session. It lands on their HUD with a 10-second, 30-second or 2-minute fuse. Ignored? Gone. No inbox. No guilt.

Ask the Operator

Your agent asks a question. The Operator finds the crewmate’s agent that already knows, reads it ephemerally, and answers in one line.

the wire

workingidlebeing readoffline

  • Reads ephemerally. A throwaway copy of the agent’s session writes the answer. The copy is never saved.
  • Keeps only the answer. The question and the answer are stored. What was read never reaches soopdoop’s servers.
  • Tells you. Your light turns purple while it reads, and every read is logged on your Mac.
  • Private stays home. Folders you mark private are never read, never summarized, never shown.

// rules that do not bend

The fine print, in big print.

01

Agents never talk to each other.

Every question goes through the Operator. No agent DMs. No swarm.

02

Every read is ephemeral.

One question, one answer. The question and the answer stay; what was read does not.

03

Private means private.

Mark a folder private and its agents are never read, never summarized, and never shown to friends.

04

Purple means reading.

If the Operator is reading your agent, your light is purple. Always. There are no silent reads.

05

Everything expires.

Knocks last seconds. Questions last 90. The server enforces it, not your willpower.

06

No token flexing.

The board counts help, not spend. There is no leaderboard of who burned the most tokens.

// install

One line. About a minute.

Terminal
  1. Run the line. It installs soopdoop, builds the Mac app on your Mac, and starts it.
  2. Sign in with Superset in the HUD. Your browser opens Superset’s page once.
  3. Pick a handle. Use your Superset handle and your Superset profile links up too.
  4. Invite your crew. Menu bar → Invite someone new. Each invite works once, for 7 days.

You need

  • macOS 14+
  • a Superset account
  • Claude Code
  • Xcode command line tools

No Xcode tools? xcode-select --install, then run the line again.

Got an invite?

Paste the line from the message instead. It is the same line with your invite code on the end, and it makes you friends with whoever sent it.

What it changes on your Mac
  • Adds its hooks to ~/.claude/settings.json, next to Superset’s, after backing up your file.
  • Builds ~/Applications/soopdoop.app from source, signed for your Mac only.
  • Runs four small background services that start at login: the agent, the daemon, the HUD and the updater.
  • Adds the ask_operator tool to Claude Code.
  • Keeps everything else in ~/.soopdoop.

Updates install themselves. soopdoop uninstall takes it all back out.

// questions

Asked and answered.

Is this made by Superset?

No. soopdoop is an independent, open-source companion. It runs beside an unmodified Superset and uses only public surfaces: Superset sign-in and Claude Code hooks.

What can my friends see?

That you are online, how many agents you run, your rank, and agent names only if you share them. Never your code or your prompts. When a friend asks the Operator something, a throwaway copy of one of your open agents may read its conversation to answer, ephemerally: the copy is never saved, and friends see only the answer. Your light turns purple while it does.

Is the Operator switched on?

It is warming up. Until it is switched on, it politely tells you so. Presence, knocks, ranks and the HUD work today.

Codex? Cursor? Something else?

Claude Code today. More harnesses later.

Linux? Windows?

The HUD app is macOS only for now. The web rail runs anywhere if you start it by hand.

What does it cost?

Nothing. It is MIT licensed, and the code is on GitHub.

How do I get rid of it?

soopdoop uninstall removes the hooks, the background services, the app and the tool.

Why “soopdoop”?

Say it out loud. Now say it to a coworker. That is the whole product.

Your Superset, with your crew in it.
