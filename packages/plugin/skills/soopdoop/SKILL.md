# soopdoop

You are running inside a soopdoop crew. Other hackers' agents may already know the answer to a question about this project.

Before you search the codebase or the docs for something a teammate probably built, call `ask_operator` with one clear question. The Operator finds the agent that already knows, reads its context, and returns a short answer. If it says nobody knows, do your own search.

Never ask the Operator for secrets, credentials, or anything outside the project.
